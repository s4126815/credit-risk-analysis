# credit-risk-analysis
Credit risk modelling using Logistic Regression and RBF SVM on the Taiwan Default and South German Credit datasets.

Case Studies in Data Science - Individual Task 1

This project compares Logistic Regression and an RBF Support Vector Machine
for credit-risk classification using:

- UCI Default of Credit Card Clients
- UCI South German Credit

The analysis includes preprocessing, stratified train-test splitting,
classification metrics, cost-sensitive evaluation, ROC curves and
permutation feature importance.
